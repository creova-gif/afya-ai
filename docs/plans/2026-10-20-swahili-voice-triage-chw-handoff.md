## Executive Summary & Core Wedge

Afya AI addresses a fundamental healthcare bottleneck across Tanzania and East Africa: patients experience delays, language friction, and anxiety when articulating symptoms, while overburdened Community Health Workers (CHWs) and dispensary nurses spend critical clinical minutes manually extracting fragmented histories.

This plan establishes an **End-to-End Voice & Text Swahili Triage Engine with Clinician SBAR Note Handoff**. Patients speak or type naturally in conversational Swahili or Sheng. Afya AI conducts an empathetic, culturally tuned clinical intake based on East African primary care protocols, outputting both an actionable Swahili patient guidance card and an immediate, standardized SBAR clinical note with one-tap WhatsApp dispatch to local CHWs.

---

## Hardened Architecture & Cross-Platform Reliability

Following independent technical review, the architecture addresses core mobile realities:

1. **Cross-Platform Audio Capture**: Runtime MIME-type negotiation supporting both Android Chrome (`audio/webm`) and iOS Safari (`audio/mp4`).
2. **Local PII Air-Gap**: Patient names, national IDs, and exact phone numbers remain strictly in browser local state. Clinical symptom prompts are sent anonymously; patient metadata is re-stitched client-side only at note dispatch.
3. **Truncation-Proof SBAR WhatsApp Export**: Compact, highly structured clinical snippet (< 800 characters) pre-formatted for WhatsApp messaging with configurable CHW recipient number.
4. **Accessible Visual Triage UI**: High-contrast, large-type Swahili patient guidance card designed for low-literacy clarity (bypassing unsupported mobile browser Swahili TTS synthesis).
5. **Pre-Seeded Demonstration Presets**: 3 one-click clinical scenarios (Severe Malaria, Maternal Red Flags, Hypertensive Urgency) for instantaneous testing and offline demonstration.

## Section 2: Error & Rescue Map

| Method / Codepath | What Can Go Wrong | Exception Class | Rescued? | Rescue Action | User Sees |
|---|---|---|---|---|---|
| `recorder.start()` | Mic permission denied | `NotAllowedError` | Yes | Switch automatically to Swahili text input | "Ruhusa ya maikrofoni inahitajika. Unaweza kuandika hapa." |
| `recorder.init()` | Audio format unsupported | `NotSupportedError` | Yes | Negotiate fallback MIME (`audio/mp4` -> `audio/webm` -> `text`) | Smooth transition without user crash |
| `triageService.infer()` | Network drop / API timeout | `TimeoutError` | Yes | 1 retry with exponential backoff, then local clinical triage fallback | "Mtandao umekatika kidogo. Tunatumia mwongozo wa dharura wa ndani." |
| `triageService.infer()` | Malformed LLM JSON | `ZodError` | Yes | Fallback to deterministic rule-based triage assessment | Structured safety summary; never raw LLM text |
| `triageService.validate()` | Critical red flags (hemorrhage, coma) | `EmergencyEscalation` | Yes | Immediate banner highlighting nearest emergency facility & ambulance hotline | RED alert badge with one-tap call button |
| `dispatchService.whatsapp()` | URL encoding failure | `URIError` | Yes | Sanitize payload string, copy plain text to clipboard | "Ujumbe umenakiliwa. Fungua WhatsApp na ubandike." |
